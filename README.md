# Peanut Cam

Your real eyes and mouth, live, on a 3D peanut, your own pictures or imported 3D models. Web and Android. The Android app can also stream the scene live over RTMP (TikTok, OBS, YouTube, Twitch…): see [docs/LIVE_STREAMING.md](docs/LIVE_STREAMING.md).
